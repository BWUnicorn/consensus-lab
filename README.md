# 共识实验室：第二阶段实时联机版

这一版已经将模拟玩家替换为真实玩家。服务器使用 Node.js 自带能力运行，不需要安装第三方依赖。玩家通过房间码加入，服务器负责倒计时、锁定答案、统一结算与广播排行榜。

## 启动方法

电脑需要安装 Node.js 20 或更高版本。在项目目录打开终端，运行：

```bash
npm start
```

然后在电脑浏览器打开：

```text
http://localhost:4173
```

## 在同一网络用两台设备测试

1. 确保电脑和手机连接同一个 Wi-Fi。
2. 在 Windows 终端运行 `ipconfig`，找到电脑的 IPv4 地址，例如 `192.168.1.8`。
3. 电脑保持 `npm start` 正在运行。
4. 手机浏览器访问 `http://192.168.1.8:4173`，把示例地址替换为你的真实 IPv4 地址。
5. 一台设备创建房间，另一台输入房间码加入。

如果手机打不开，通常是 Windows 防火墙阻止了 Node.js。仅允许“专用网络”访问即可，不要开放到不可信的公共网络。

## 当前联机功能

- 2～10 人实时房间
- 五位随机房间码
- 房主开始和切换关卡
- 服务器默认统一 60 秒倒计时，可通过 `ROUND_SECONDS` 环境变量调整
- 每名玩家每关只能提交一次
- 答案在本轮结束前保持隐藏
- 全员提交后提前结算
- 选择分布、个人得分原因与排行榜同步
- 页面断线后自动尝试重连
- 六小时未活动的房间自动清理
- 房主可在等待大厅添加或移除 AI 玩家，总人数仍不超过 10 人
- AI 会随机获得“保守者”“激进派”“合作者”“机会主义者”或“随机者”身份，并在每轮开始后自动作答
- 内置 20 道博弈题，每局开始时无重复随机抽取 10 道
- 首页支持在线快速匹配，至少两名真人时进入 15 秒集结倒计时
- 单人等待 20 秒仍未匹配到真人时，由服务器自动补足到 4 人
- 匹配房间自动开局，并在每轮结算展示 8 秒后自动进入下一轮

## AI 玩家策略

AI 玩家不调用大模型，也不产生 API 费用。房主每次点击“添加AI玩家”时，服务器会随机分配一种身份：

- 保守者：每道题采用预先配置的稳妥选择
- 激进派：每道题采用预先配置的高风险或高收益选择
- 合作者：优先促成合作、维护公共资源或提高团队整体收益
- 机会主义者：优先搭便车、抢占稀缺收益或利用其他玩家的选择
- 随机者：每轮从该题的有效选项中随机选择

每道题都分别配置了四种固定人格的答案，因此随机抽题不会打乱 AI 策略；随机者仍从有效选项中随机作答。AI 会在每轮开始后的约 1.8～5.2 秒提交答案，提交前不会向其他玩家公开选项。

## 在线匹配参数

匹配队列暂时保存在服务器内存中，适合当前单服务器部署。默认参数可以通过 Docker 环境变量调整：

- `MATCH_COUNTDOWN_SECONDS`：两名真人匹配成功后的集结时间，默认 15 秒
- `MATCH_AI_FILL_SECONDS`：单人等待多久后由 AI 补位，默认 20 秒
- `MATCH_TARGET_PLAYERS`：AI 补位后的目标人数，默认 4 人
- `AUTO_NEXT_SECONDS`：匹配房每轮结算展示时间，默认 8 秒

## 使用 Docker 部署

服务器安装 Docker 后，在项目目录运行：

```bash
docker build -t consensus-lab .
docker run -d --name consensus-lab --restart unless-stopped -p 80:4173 consensus-lab
```

浏览器访问服务器公网 IP 即可。更新版本时重新拉取代码、构建镜像并替换容器。

## 文件作用

- `server.js`：房间、玩家、实时消息、倒计时和权威结算。
- `question-bank.js`：20 道题目、选项、计分规则和 AI 策略答案。
- `QUESTION_BANK.md`：题目清单及五种 AI 身份的答案对照表。
- `app.js`：浏览器交互以及与服务器通信。
- `index.html`：页面结构。
- `styles.css`：界面与手机适配。
- `logo.svg`：极简几何品牌标志。
- `package.json`：启动和检查命令。

## 当前限制

房间数据暂时保存在服务器内存中，服务器或容器重启后房间会消失。下一阶段可增加持久化数据库、自定义题库和房主 AI 配置。
