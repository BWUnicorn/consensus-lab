# 共识实验室：第二阶段实时联机版

这一版已经将模拟玩家替换为真实玩家。服务器使用 Node.js 自带能力运行，不需要安装第三方依赖。玩家通过房间码加入，服务器负责倒计时、锁定答案、统一结算与广播排行榜。

## 启动方法

电脑需要安装 Node.js 20 或更高版本。在项目目录打开终端，运行：

```bash
npm start
```

然后在电脑浏览器打开：

```text
http://localhost:4173
```

## 在同一网络用两台设备测试

1. 确保电脑和手机连接同一个 Wi-Fi。
2. 在 Windows 终端运行 `ipconfig`，找到电脑的 IPv4 地址，例如 `192.168.1.8`。
3. 电脑保持 `npm start` 正在运行。
4. 手机浏览器访问 `http://192.168.1.8:4173`，把示例地址替换为你的真实 IPv4 地址。
5. 一台设备创建房间，另一台输入房间码加入。

如果手机打不开，通常是 Windows 防火墙阻止了 Node.js。仅允许“专用网络”访问即可，不要开放到不可信的公共网络。

## 当前联机功能

- 2～10 人实时房间
- 五位随机房间码
- 房主开始和切换关卡
- 服务器统一 30 秒倒计时
- 每名玩家每关只能提交一次
- 答案在本轮结束前保持隐藏
- 全员提交后提前结算
- 选择分布、个人得分原因与排行榜同步
- 页面断线后自动尝试重连
- 六小时未活动的房间自动清理

## 文件作用

- `server.js`：房间、玩家、实时消息、倒计时和权威结算。
- `app.js`：浏览器交互以及与服务器通信。
- `index.html`：页面结构。
- `styles.css`：界面与手机适配。
- `logo.svg`：极简几何品牌标志。
- `package.json`：启动和检查命令。

## 当前限制

房间数据暂时保存在服务器内存中。服务器重启后房间会消失，也还没有部署到公网。下一阶段将增加持久化数据库和公开网址。
